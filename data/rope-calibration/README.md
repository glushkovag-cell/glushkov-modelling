# Калибровка калькулятора канатов

Воспроизводимый датасет и скрипты для модели диаметра канатов. Активная модель —
`log-dtex-quadratic-no-load` (контракт v2, algorithmVersion 4.0.0, без груза);
её описание — `docs/rope-calculator/model.md`.

## Файлы

| Файл | Назначение | SHA-256 |
| --- | --- | --- |
| `threads_merged.xlsx` | исходная таблица, лист «Общая таблица», не редактируется | `4924e12a2046b9fb034cee444b285fb22da43904ce6e923564ecdd24ebb056eb` |
| `normalized.csv` | нормализованная таблица: все 186 строк, выведенные поля отдельно | `4b015f8991f4fc816dd4618fdd635715f6ae4bb056ecd132751b0c488b0dc0db` |
| `calibrate_no_load.py` | очистка выборки, усреднение, подбор и LOFO активной модели | — |
| `no-load/` | сгенерированные артефакты активной модели | см. `no-load/SHA256SUMS.json` |
| `legacy-load/` | архив калибровки с учётом груза (algorithmVersion 3.0.0) | — |

Хеши `threads_merged.xlsx` и `normalized.csv` должны совпадать точно. Хеши
`no-load/*.json` включают версии numpy/scipy и полные float-значения, поэтому
могут отличаться на другой сборке; `--check` сверяет коэффициенты и метрики с
явными допусками, а не хеши.

## Запуск

```bash
python3 -m pip install -r data/rope-calibration/requirements.txt
python3 data/rope-calibration/calibrate_no_load.py           # пересобрать no-load/*
python3 data/rope-calibration/calibrate_no_load.py --check   # проверить без записи
```

`--check` падает при расхождении коэффициентов больше 1e-6 относительно или
метрик больше 0.02 процентного пункта, а также при изменении CSV/JSON.

## Правила выборки

- x — dTex исходной нити; n — первое число в конструкции `n×3`; прядей
  всегда 3; D — диаметр, мм.
- 143 измерения типа P (130 старых, 13 новых; строки Excel 175–187). Из
  рабочей выборки удалены строки 179, 180, 181 (UNI-C 20D 22.22 dTex);
  строки 182 (n=2, 0.086 мм) и 183 (n=1, 0.050 мм) остаются. Исходные записи
  не удаляются.
- Десять групп «нить + dTex + n» усреднены (идентификация: штрихкод, иначе
  точная серия, иначе производитель; разные штрихкоды не объединяются;
  правило `(Dmax − Dmin)/Dmin ≤ 15%`; Skala 360 n=2 усреднена отдельно по
  решению пользователя). Каждая агрегированная строка имеет вес 1, сырые
  значения остаются в журнале.
- Получено 130 рабочих строк; в подборе 128: строки Excel 95 и 133 остаются
  прежними исключениями. Среди 128 — 121 старая и 7 новых строк.
- Цель подбора — сумма квадратов относительных ошибок; вес груза не
  используется. LOFO по 22 семействам: семейство исключается целиком;
  `N100`/`poliestere 300` объединены, `M702`/`M782` объединены.

## Модель и метрики

`D = exp(c0 + c1·u + c2·v + c3·u²)`, `u = ln(x/300)`, `v = ln(n)`.

Воспроизведённые метрики (допуск сверки 0.02 п.п.):

| Метрика | Значение |
| --- | --- |
| RMSPE обучение | 8.866% |
| RMSPE LOFO | 10.199% |
| MAPE LOFO | 6.534% |
| MAE / RMSE LOFO | 0.03596 / 0.04496 мм |
| LOFO, старые 121 | 7.459% / 5.546% |
| LOFO, новые 7 | 30.664% / 23.607% |
| Обучение на 121, проверка на 7 | 58.638% |

Полные значения, журнал усреднения, исключения и остатки — в
`no-load/results.json`.
