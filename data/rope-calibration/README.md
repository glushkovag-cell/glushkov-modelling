# Калибровка калькулятора канатов с учётом груза

Воспроизводимый датасет и скрипт для алгоритма 3.0.0 калькулятора канатов
(`rope-calculator-worker`). Решения и контекст —
`docs/rope-calculator/load-v2/decisions.md`.

Хеши `coefficients.json` и `results.json` относятся к сохранённым файлам.
Последние знаки подобранных чисел могут отличаться на другой сборке
scipy/BLAS, поэтому `--check` сравнивает их с точностью до 8 значащих цифр.
Хеши `threads_merged.xlsx` и `normalized.csv` должны совпадать точно.

## Запуск

```bash
python3 -m pip install -r data/rope-calibration/requirements.txt
python3 data/rope-calibration/calibrate.py           # пересобрать CSV и JSON
python3 data/rope-calibration/calibrate.py --check   # сверить без записи
```

`--check` также падает, если коэффициенты в Worker отличаются от подобранных
больше чем на 1e-6 (относительно).

## Правила выборки

- x — dTex исходной нити; n — первое число в конструкции `n×3`; прядей
  всегда 3; S = 3·x·n; w — груз, г; D — диаметр, мм.
- В выборку входят строки типа P с dTex, фактическим диаметром и грузом:
  143 измерения (130 старых, 13 новых, строки Excel 175–187).
- У новых строк тип пустой; по конструкции `n×3` принят P. Исходное поле не
  перезаписывается: в CSV есть `ropeType` и `ropeTypeNormalized`.
- Из подбора исключены строки Excel 95 (Skala 240 5×3, 0.825 мм) и 133
  (Tera 30 2×3, 1.000 мм). Строки сохранены. Новые выбросы не удалялись.
  В калибровке 141 наблюдение (128 старых, 13 новых).
- LOFO: 22 семейства нитей; семейство исключается из обучения целиком, со
  всеми свивками и повторами. Sew-all, N100 и poliestere 300 dTex
  объединены; M702 и M782 объединены. Метрики взвешены по строкам.

## Модель и стратегии

`D = a · x^b · n^c · (w/200)^loadExponent`. Цель подбора — сумма квадратов
относительной ошибки `(Dcalc − Dmeasured) / Dmeasured`.

| Стратегия | Что подбирается |
| --- | --- |
| `actualLoad` | один набор по фактическому грузу, применяется в обоих режимах |
| `separate` | ручной режим — по фактическому грузу, авто — по рекомендованному |
| `shared` | один набор по обоим режимам с равным вкладом (282 остатка от 141 измерения); принят для алгоритма 3.0.0 |

Метрики для каждой стратегии: RMSPE, MAPE, MAE, RMSE, смещение (в % и мм)
для обучения и LOFO, отдельно для всех, старых и новых измерений.

Воспроизведённые значения (все 141 наблюдение):

| Стратегия | RMSPE обучение, ручной / авто, % | RMSPE LOFO, ручной / авто, % |
| --- | --- | --- |
| `actualLoad` | 8.68 / 11.24 | 9.58 / 11.93 |
| `separate` | 8.68 / 10.97 | 9.58 / 12.08 |
| `shared` | 8.76 / 11.06 | 9.51 / 11.95 |

## Ограничения

- Груз связан с источником: XLS = 30 г, CSV/MEA = 200 г, PDF = 300 г.
  Положительная степень груза не доказывает, что нагрузка физически
  увеличивает диаметр.
- 50, 100, 150 и 250 г в данных не испытаны.
- В авто-режиме рекомендованный груз подставляется к историческому
  диаметру, измеренному при другом грузе. Это оценка подстановки, а не
  проверка изготовления. Пороги выбраны по всей таблице, поэтому LOFO с
  фиксированными порогами — условная проверка.
- Автоматический груз — стартовая рекомендация, а не оптимальная или
  безопасная нагрузка. Метрики не гарантируют точность или прочность.
