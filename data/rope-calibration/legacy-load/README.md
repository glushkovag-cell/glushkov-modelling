# Архив: калибровка с учётом груза (algorithmVersion 3.0.0)

Материалы снятого с эксплуатации контракта: модель
`a·x^b·n^c·(w/200)^loadExponent`, пороги рекомендации груза, метрики ручного и
автоматического режимов.

Сохранено как история исследования: сами измерения и наблюдавшиеся грузы не
удаляются. **Активный расчёт эту модель не использует**: модель 4.0.0 без груза
и её воспроизведение — в `../no-load/` и `../calibrate_no_load.py`. Скрипт
`calibrate.py` в этом каталоге — исторический; он не запускается в CI и не
входит в вычислительный контур Worker, UI или MCP.
