# Эталонная реализация калькулятора

`RopeCalc.html` — исходный одностраничный калькулятор, который заменяется
Worker-версией. Файл сохранён без изменений как эталон поведения.

- sha256: `e35333eded393c9307b6e3ce9b6594db7cb49a95ecc3ce5200fe748e4d51af70`
- 750 строк, зависимостей нет, каталог из 9 нитей встроен в скрипт.

## Почему файл не редактируется

Из него программно извлекаются:

- выражение из `function diameterByDtex(dtex, threads)` — единственный источник
  формулы для фикстур и тестов;
- список `THREAD_CATALOG` — 9 эталонных нитей;
- константа `MAX_DEVIATION = 0.15` — допуск обратного подбора;
- правило вывода почти нулевого отклонения (`|pct| < 0.005` → `0.00%`).

Любая правка файла сдвинет эталонные значения. Если поведение нужно изменить
намеренно, это делается в спецификации и коде Worker, а не в этом файле.

## Как пересобрать фикстуры

```bash
# Пересобрать reference.json и проверить снимок CMS
node scripts/gen-rope-fixtures.mjs

# Обновить снимок каталога из WordPress (нужны WP_GRAPHQL_URL и WP_GRAPHQL_SECRET)
node scripts/gen-rope-fixtures.mjs --catalog

# Проверка без записи: упадёт, если фикстуры разошлись с генератором
node scripts/gen-rope-fixtures.mjs --check
```

Скрипт печатает извлечённую формулу, число нитей, `catalogVersion` и таблицу
расхождений с эталоном. Секреты читаются из окружения или из `.env` в корне
репозитория.
