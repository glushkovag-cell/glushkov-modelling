# Встраивание в статью

Калькулятор — один Web Component. Скрипт уже подключён глобально в
`src/layouts/BaseLayout.astro`, поэтому в статье нужен только тег.

## Фрагмент для статьи

```html
<gm-rope-calculator>
  <noscript>Enable JavaScript to use the rope calculator.</noscript>
</gm-rope-calculator>
```

- `api-base` указывать не нужно: по умолчанию используется
  `https://api.glushkov-modelling.com`.
- `noscript` обязателен: без JavaScript элемент не превращается в компонент, и
  пользователь должен увидеть хотя бы пояснение.

## Порядок действий

Порядок важен: статья пререндерится, поэтому тег без задеплоенного Worker
покажет ошибку, а старый калькулятор без правки статьи останется как есть.

1. Задеплоить Worker (`docs/rope-calculator/deploy.md`).
2. Заменить старый калькулятор в статье на фрагмент выше.
3. Пересобрать и выложить сайт: push в `main` или **Actions** →
   **Deploy to VPS** → **Run workflow**.
4. Открыть статью и пройти чек-лист ниже.

## Что удалить из статьи

Старый калькулятор — это `<section class="rope-calculator">` вместе со
встроенным `<script>`, в котором есть `THREAD_CATALOG` и `diameterByDtex`.
Нужно удалить весь блок от открывающего `<section class="rope-calculator">` до
его закрывающего `</section>`, включая скрипт внутри — иначе на странице
останутся два калькулятора и два обработчика.

Проверить, что остатков нет, можно поиском по статье: `THREAD_CATALOG`,
`diameterByDtex`, `rc-calculator-mode` не должны встречаться.

## Как вставлять в WordPress

1. Открыть статью в блочном редакторе.
2. Добавить блок **Custom HTML** (или переключиться в редактор кода).
3. Вставить фрагмент и сохранить.
4. Убедиться, что тег не вырезан: снова открыть редактор кода и проверить, что
   `<gm-rope-calculator>` на месте. WordPress сохраняет неизвестные теги только
   пользователям с правом `unfiltered_html` (администратор), остальным KSES их
   вырежет.
5. Если `<noscript>` вырезается, а тег остался — фолбэк можно опустить, это не
   влияет на работу калькулятора.

## Чек-лист приёмки статьи

- [ ] В исходном коде страницы есть `<gm-rope-calculator>`.
- [ ] Калькулятор показывает `0.963 mm` для Tera 40 и 2 нитей в пряди.
- [ ] Переключение светлой и тёмной темы меняет оформление компонента.
- [ ] На ширине 390 px ничего не вылезает за экран.
- [ ] При target = 1.0 обратный подбор показывает 11 совпадений.
- [ ] В консоли браузера нет ошибок CORS и 4xx/5xx.
- [ ] Старый калькулятор исчез: на странице ровно один блок расчёта.

## Пересборка после правки статьи

Статьи собираются на этапе сборки сайта, поэтому правка в CMS не появляется на
сайте сама по себе. Нужно:

- push в `main` (любой коммит), либо
- **Actions** → **Deploy to VPS** → **Run workflow**.

## Откат статьи

В WordPress есть ревизии: **Page/Post → Revisions** — вернуть предыдущую
версию и пересобрать сайт. Старый калькулятор продолжит работать, пока не
задеплоена новая сборка.
