## Явные ограничения

- Выбранные нити не сохраняются между перезагрузками и не входят в экспорт.
  Повторный подбор после пересчёта и контроль актуальности реализованы; это
  осознанная граница этапа 3.
- `not_applicable` в полной конфигурации традиционного профиля не возникает;
  переключатель и счётчик проверены unit-тестами на синтетических строках.
- Запоздалые ответы защищены существующим номером запроса; отдельный
  fault-injection тест задержки не выполнялся.
- Фильтров по материалам нет ни в одном режиме.
- Представление хранится в `sessionStorage`, то есть в рамках вкладки.
