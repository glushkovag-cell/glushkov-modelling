# Релизная полировка UI калькулятора такелажа

Исправления по замечаниям к релизу. Расчёт, профили, фильтрация, поиск,
сортировка, экспорт и сохранение представления не менялись.

## 1. Единая система полей и типографики

Введены общие токены для раздела ввода, фильтров/группировки и результатов:

- высота input/select/button/segmented — 44 px;
- подписи контролов — 0.78 rem, 600, строчные, приглушённый цвет;
- текст контролов — 0.94 rem;
- кнопки — 44 px, 0.9 rem / 600; primary и ghost отличаются только цветом;
- заголовки секций — Cormorant 1.4 rem, заголовок узла — 1.35 rem;
- строки и таблицы — 0.92 rem, вторичный текст — 0.8 rem;
- табличные заголовки и eyebrow — 0.72 rem / 700 uppercase.

Подписи формы, фильтров, сортировки, группировки и области экспорта теперь
имеют одинаковый размер, вес и регистр. Карточки формы, профилей, фильтров и
ведомости используют одинаковые border/radius/padding (16 px).

```
Calculation totals | All 279 rows before filters | 270 calculated | 0 needs input | 9 unsupported | 0 not applicable
```

- Отдельные карточки `FIT rows` и `ENG rows` удалены.
- Нулевые значения приглушены, статус остаётся текстовым.
- FIT/ENG-значки в рассчитанных строках и `Origin` в подробностях сохранены
  по согласованию: убраны только строки из резюме.

## 3. Четыре блока управления

Панель ведомости разделена на четыре всегда видимых блока:

```
Search   — поле + счётчик N of M
Filter   — кнопка Filters + число активных условий + краткая сводка
Sort     — селект + пояснение области сортировки
Grouping — Grouped / Flat table + пояснение структуры
```

- Панель фильтров раскрывается под блоками: Node / Tier / Rigging type /
  Status, `Show not applicable`, `Clear all`.
- Активные условия остаются чипами под панелью.
- `Expand all` / `Collapse all` перенесены в заголовок grouped-ведомости
  (`Grouped by node · N sections`). В flat этого ряда нет.
- Пояснения под контролами меняются по режиму: `Within each group` /
  `Whole table`, `Node → tier → type` / `One table`.

## 4. Стабильная геометрия

- Четыре блока — фиксированная CSS Grid: 4 колонки на широком экране,
  2×2 на 768–900, одна колонка на ≤640.
- Высота блоков не меняется при переключении grouped/flat; скрывается только
  grouped-заголовок ниже панели.
- Позиция панели управления сохраняется при переключении режима: измеряется
  `getBoundingClientRect().top` до и после рендера и при необходимости
  корректируется scroll.
- `scrollbar-gutter: stable` предотвращает горизонтальный сдвиг при
  появлении/исчезновении скроллбара.
- Кнопки и селекты результатов приведены к одной высоте 44 px, поэтому
  заголовок результатов не меняет высоту.
