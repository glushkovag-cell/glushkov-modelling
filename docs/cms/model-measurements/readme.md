# Конфигурация измерений моделей в WordPress

## Назначение

JSON-экспорты настроек справочников и ACF-полей.
Используются для контроля изменений и ручного восстановления конфигурации.

## Типы записей

- measurement_defi — Виды измерений
- model_element — Элементы модели

## Порядок работы

1. Настройки редактируются в административной панели WordPress.
2. После изменения выполняется повторный JSON-экспорт затронутых объектов.
3. Экспорт заменяет соответствующие файлы в этой папке.
4. Изменения проверяются и сохраняются Git-коммитом.

## Ограничения

- Файлы не подключены к автоматическому развёртыванию.
- Размещение в репозитории само по себе не меняет конфигурацию WordPress.
- Экспорты настроек не являются резервной копией значений измерений моделей.

## Проверка GraphQL

После изменения настроек полей или CPT проверить фактическую GraphQL-схему
и актуализировать контракты, запросы и типы потребителей при необходимости.
